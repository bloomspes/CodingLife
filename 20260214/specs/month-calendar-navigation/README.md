# 월간 달력 기본 보기 및 이동

## Background

달력 앱의 출발점으로, 사용자가 현재 월을 한눈에 보고 월 단위로 이동할 수 있는
기본 화면이 필요하다.

## Goal

오늘 날짜를 기준으로 이번 달 달력을 그려 주고, 이전/다음 달 이동과 오늘로
돌아가기 기능을 제공한다.

## How it works

### 기본 표시

- 앱을 열면 오늘 날짜 기준의 이번 달 달력을 그린다.
- 달력 상단에 연월을 표시한다.
- 오늘 날짜는 다른 날짜보다 도드라지게 표시한다.

### 월 이동

- 상단 왼쪽 버튼으로 이전 달로 이동한다.
- 상단 오른쪽 버튼으로 다음 달로 이동한다.

### 오늘로 이동

- 별도의 "오늘" 버튼을 제공한다.
- 버튼을 누르면 언제나 오늘이 속한 달로 이동한다.

## Manual Test Strategy

- 최신 브라우저(Chrome, Firefox, Safari 중 1개 이상)에서 테스트한다.
- 초기 진입 시 오늘 달과 연월, 오늘 강조 표시를 확인한다.
- 이전/다음 버튼을 여러 번 눌러 월 이동이 누적 적용되는지 확인한다.
- 오늘 버튼을 눌러 오늘 달로 복귀하는지 확인한다.
- 월 경계(1월 ↔ 12월) 이동이 정상인지 확인한다.
