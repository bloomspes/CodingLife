# 캘린더 웹 앱

오늘 날짜를 분명하게 보여주는 작은 웹 캘린더 앱입니다.

현재 상태: Vite + React + TypeScript + Tailwind CSS + TanStack Router 진입점을
구성한 상태입니다. AGENTS.md와 PLAN.md에 정리된 순서대로 기능을 차례대로 구현
중입니다.

## 실행 방법

### Node 버전 맞추기

```bash
nvm use
```
또는 `.nvmrc`에 적힌 버전(예: `20.12.2`)과 동일한 Node를 사용한다.

### pnpm 설치

```bash
npm install -g pnpm
```

### 의존성 설치

```bash
pnpm install
```

### 개발 서버 실행

```bash
pnpm dev
```

터미널에 표시되는 주소(기본값: `http://localhost:5173`)를 브라우저에서 연다.

## 제공 기능

- TanStack Router 루트 라우트와 홈 진입점 구성

기능을 하나 구현할 때마다 이 README를 함께 업데이트합니다.
