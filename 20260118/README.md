# 캘린더 웹 앱

오늘 날짜를 분명하게 보여주는 작은 웹 캘린더 앱입니다.

현재 상태: Vite + React + TypeScript + Tailwind CSS 기본 구조와 엔트리 파일까지 생성된 상태입니다.  
AGENTS.md와 PLAN.md에 정리된 내용에 따라, React + TypeScript + Tailwind CSS + TanStack Router + pnpm 스택으로 구현합니다.

## 설치 및 실행 (초기)
- Node: `.nvmrc`에 명시된 버전(예: 20.12.2) 사용
- 패키지 설치: `pnpm install`
- 개발 서버 실행: `pnpm dev`
