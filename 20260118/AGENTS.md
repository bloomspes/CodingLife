# 캘린더 웹 앱

## 목표
- “오늘 날짜”를 분명하게 보여주는 단순한 웹 캘린더 페이지를 만든다.
- 날짜 표기는 사람이 읽기 좋은 한국어 형식을 사용한다
  (예: `2026년 1월 18일 (토)`).
- 화면 어디에서도 “오늘”이 한 눈에 들어오도록 시각적으로 강조한다.

## 기본 원칙
- 모든 자연어(답변, 설명, 변수/파일 설명)는 **반드시 한국어로만** 작성한다.
- 영어는 필요할 때 예시 코드, 파일명, 명령어 등에만 사용한다.
- 가벼운 웹 앱을 목표로 하며, 선택한 스택(React + TypeScript + Tailwind + TanStack Router)을 **최소한의 복잡도로** 사용한다.
- 불필요한 외부 라이브러리나 CDN 의존성을 피하고, 로딩 속도를 우선한다.
- 새로운 결정이나 규칙이 생기면, 대화로만 두지 말고 **반드시 이 파일(AGENTS.md)을 먼저 고쳐서 반영한다.**
- 프로젝트 시작 시 `README.md` 파일을 바로 만들고, **작업이 끝날 때마다 README 내용을 함께 업데이트**한다.
- `PLAN.md`는 **체크리스트 형식**으로 유지하며, 실제 작업이 진행될 때마다 항목 완료 여부를 계속 업데이트한다.
- Git 커밋은 **아주 작은 작업 단위**로 쪼개고, 각 커밋 메시지는 완료한 체크리스트 항목이 무엇인지 드러나는 **의미 있는 한국어 한 줄**로 작성한다.

## 기술 스택
- 렌더링: 단일 페이지 애플리케이션(SPA) – React 기반.
- 프론트엔드: `React` + `TypeScript` + `Tailwind CSS`.
- 패키지 매니저: `pnpm`을 기본으로 사용한다.
- 런타임/Node 버전:
  - Node.js는 `nvm`으로 관리하며 **Node 20 LTS (20.12.2)** 버전을 사용한다.
  - `20.12.2`는 이 파일을 작성하는 시점 기준 **LTS 최신 버전**이다.
  - `.nvmrc` 파일에는 `20.12.2`를 명시해 버전을 고정한다.
  - Node 버전을 변경할 때는 `.nvmrc`와 이 섹션에 구체 버전을 함께 기록한다.
- 라우팅:
  - `@tanstack/react-router`를 사용한다.
  - 라우트는 **폴더/파일 구조와 URL이 최대한 1:1로 매칭**되도록 `src/routes/` 폴더를 기준으로 설계한다.
  - 새로운 페이지를 추가할 때는 먼저 `src/routes/`에 폴더·파일 구조를 만든 뒤, 해당 라우트 컴포넌트를 구현한다.
- 빌드 도구: `Vite`(React + TypeScript 템플릿) 사용. Tailwind를 적용한 설정을 사용하고, 설정을 변경하면 이 파일에 이유와 주요 설정을 요약해서 남긴다.
- 배포: 빌드 결과(`dist/`)를 정적 호스팅(GitHub Pages, Vercel, Netlify 등)에 올린다.

## 파일 구조
- `index.html` – 루트 HTML
- `src/main.tsx` – 진입점, ReactDOM + TanStack Router Provider 마운트
- `src/routes/` – TanStack Router용 라우트 정의 폴더 (폴더 구조 = URL 구조)
  - `src/routes/__root.tsx` – 루트 레이아웃/루트 라우트, 공통 레이아웃 및 `<Outlet />` 포함
  - `src/routes/index.tsx` – 기본(홈) 페이지, “오늘 날짜 캘린더” 화면 구현
  - 추가 페이지는 URL 구조에 맞춰 하위 폴더/파일로 매칭
- `src/components/` – 공통 UI 컴포넌트 정리
- `tailwind.config.js` / `postcss.config.js` – Tailwind 설정

## 테스트 및 확인
- 브라우저의 현재 시간대 기준으로 “오늘 날짜”가 올바르게 표시되는지 확인한다.
- 모바일 뷰포트(좁은 화면)에서 날짜와 “오늘” 강조 표시가 잘 보이는지 확인한다.
- 브라우저 콘솔에 오류나 불필요한 로그가 없는지 확인한다.

## 도메인 규칙
- 달력의 한 주는 **일요일부터 토요일까지**로 구성한다.
- 달력 요일 헤더는 `일, 월, 화, 수, 목, 금, 토` 순서로 표시한다.
