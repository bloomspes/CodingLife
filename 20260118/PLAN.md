## 달력 페이지 기능 요구사항

- [ ] 초기 진입 경로는 `/` 하나이며, 이 페이지에서 **오늘 날짜 텍스트 + 월 단위
      달력 뷰**를 동시에 보여준다.
- [x] 상단에는 앱 제목(예: “오늘 캘린더”)과 한 줄 설명(“오늘 날짜를 분명하게
      보여주는 작은 캘린더”)을 표시한다.
- [ ] 오늘 날짜 텍스트 영역
  - [x] 형식은 `YYYY년 M월 D일 (요일)`로 고정한다.
  - [x] 요일은 한국어로 `일, 월, 화, 수, 목, 금, 토` 중 하나로 표기한다.
  - [x] 화면 상단 중앙에 크게 표시한다.
- [ ] 월 달력 뷰 영역
  - [ ] 주 시작 요일은 **일요일**로 고정한다.
  - [ ] 요일 헤더 행(일~토)과 그 아래 날짜 그리드를 7열로 렌더링한다.
  - [ ] 현재 보고 있는 달의 1일이 시작되는 요일에 맞춰 빈 칸/이전 달 날짜 등은
        표시하지 않고, **해당 월의 날짜만** 채운다.
- [ ] “오늘” 강조 규칙
  - [ ] 달력 그리드에 오늘 날짜가 포함되어 있을 때, 해당 날짜 셀에만
        배경색/테두리 등으로 강조 스타일을 적용한다.
  - [ ] 오늘이 현재 보고 있는 달 범위 밖일 때는 달력에서는 어떤 셀도 강조하지
        않고, 상단의 오늘 날짜 텍스트로만 오늘을 알 수 있게 한다.
- [ ] 월 이동/오늘로 돌아가기
  - [ ] 달력 상단에 “이전 달” 버튼과 “다음 달” 버튼, “오늘로” 버튼을
        배치한다.
  - [ ] “이전 달”/“다음 달” 버튼 클릭 시, 보고 있는 달이 정확히 한 달씩
        이동한다.
  - [ ] “오늘로” 버튼 클릭 시, 보고 있는 달을 오늘이 속한 달로 되돌리고,
        (포함되는 경우) 오늘 날짜 셀을 다시 강조한다.
- [ ] 반응형 규칙
  - [ ] 모바일(좁은 화면)에서는 “오늘 날짜 텍스트 → 컨트롤(이전/ 다음/오늘로)
        → 달력 뷰” 순으로 세로 스택한다.
  - [ ] 데스크톱(넓은 화면)에서는 전체 영역을 중앙에 배치하고, 텍스트와 달력의
        좌우 여백을 맞춰 시각적으로 귍형 있게 정렬한다.
